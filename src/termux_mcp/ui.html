2 · Tunnel

Claude mengakses perangkat lu lewat alamat publik. Pilih cara membuatnya.

Tanpa akun, langsung jalan. Alamat berubah setiap server dinyalakan ulang, jadi konektor di Claude perlu diperbarui.

Alamat tetap, cukup diisi sekali di Claude. Perlu akun ngrok gratis.

Pasang ngrok dulu dari ngrok.com/download.

3 · Pasang di Claude

Dilakukan sekali. Tombol Salin mengisi clipboard.

  1. Buka app Claude, masuk ke pengaturan Konektor, lalu pilih tambah konektor kustom.
  2. Isi alamat server:
    Nyalakan server dulu
  3. Tambahkan header dengan nama ini:
    x-api-key
  4. Isi nilai header dengan token lu:
    Token dari langkah 1
  5. Simpan, lalu aktifkan konektornya di percakapan.
